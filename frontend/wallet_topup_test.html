Webhook note

Your server also has POST /api/v1/wallet/razorpay/webhook (listens for payment.captured, credits the same top-up row). Razorpay can't reach localhost, so to test it expose port 8080 (e.g. ngrok http 8080) and register https://<tunnel>/api/v1/wallet/razorpay/webhook in the Razorpay Dashboard with the secret from RAZORPAY_WEBHOOK_SECRET. Whichever of verify or webhook arrives first credits the wallet; the other should be a no-op.
